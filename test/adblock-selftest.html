How to read this (important)

  1. Serve over http, not file:// — DNR rules apply most faithfully to a real page. From this folder run python3 -m http.server 8099 and open http://localhost:8099/test/adblock-selftest.html.
  2. Establish the noise floor. Disable ShieldBlock (or any blocker), reload, Run test. Anything still "blocked" is a dead host / DNS failure, not a real block — note those endpoints and ignore them in the real run.
  3. Real run. Enable ShieldBlock, let a filter sync finish (popup → Support → Run check), reload, Run test. Real blocked rate = blocked-with-extension − dead-host floor.
  4. Compare. Repeat with uBO Lite / AdGuard installed instead. The deltas tell you exactly which categories you trail in.

⚠️ This is a directional smoke-test, not an authority. For the definitive score use the external suites listed in BENCHMARKS.md (d3ward toolz, adblock-tester.com, EFF Cover Your Tracks). The endpoint list below is editable — keep it fresh.
