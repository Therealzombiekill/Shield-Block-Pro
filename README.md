# ShieldBlock Pro

ShieldBlock Pro is a free, privacy-first ad blocker for Chrome and Firefox. No account required, no data collection — everything runs locally on your device.

## Features

### Ad Blocking
Filters ads across the entire web using 22 community-maintained filter lists, including EasyList, uBlock Origin filters, AdGuard, and regional lists. Filter lists update automatically every 12 hours.

### Cookie Banner Rejection
Automatically rejects cookie consent dialogs from 60+ consent management platforms. Banners are declined at the source rather than simply hidden from view.

### Anti-Fingerprinting
Randomizes Canvas, WebGL, AudioContext, Battery API, and screen resolution readings so trackers cannot build a device fingerprint across sites.

### Social Media Cleanup
Removes sponsored posts and promoted content from Facebook, Instagram, Reddit, X, LinkedIn, and TikTok feeds across 30+ languages.

### URL Tracking Parameter Removal
Strips 80+ tracking parameters from every URL before requests are made, including fbclid, utm_*, ttclid, gclid, and others.

### Anti-Adblock Bypass
38 scriptlets neutralize adblock-detection scripts on sites that actively fight back against filtering.

## Platform-Specific Blocking

Dedicated ad removal for YouTube, Twitch, Spotify, Amazon, Hulu, and Kick — including pre-roll and mid-roll video ads.

## Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| Alt + Shift + S | Open ShieldBlock popup |
| Alt + Shift + B | Toggle blocking on current site |
| Alt + Shift + P | Activate element picker |

Right-click any ad you spot and select **ShieldBlock: Hide this element** to add a custom hide rule instantly.

## Privacy

All data is stored locally on your device. ShieldBlock Pro makes no outbound connections except to download filter list updates from public repositories. No personal data is ever collected or transmitted.
